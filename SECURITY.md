# Security

If you find a security or privacy problem in LocalScribe (for example a way data could leave the device without
the user choosing it, or a weakness in library encryption), please **don't open a public issue**.

Report it privately through GitHub's [private vulnerability reporting](../../security/advisories/new) for this
repository. Include what you found, how to reproduce it, and what an attacker could do with it.

You'll get an answer within a few days. Fixes for confirmed issues are released as soon as possible, and you're
credited in the release notes unless you'd rather not be.
